我有一个用了很多年的笔记习惯：OneNote。

它的层级结构、自由排版、多设备同步，都很适合"想到什么记什么"。但每次往里写代码笔记、写技术文档，就会卡住——因为它**不认 Markdown**。

写 `# 标题`，它就是 `# 标题`；写三个反引号，它还是三个反引号。想去别的编辑器里写完再贴回来，格式又全乱。

<!--more-->

## 一个不改变习惯的解法

NoteMark 是一个 Windows 端的 OneNote 插件。它的设计原则只有一句：**不改变你用 OneNote 的习惯。**

安装后重启 OneNote 就能用。写 Markdown 的时候还是照常写，写完按一个键，它变成排版好的页面。

## 六个快捷键，就是全部

- **Enter**：渲染当前段落
- **Ctrl + Enter**：渲染选中内容，跨行选区也能整块转换
- **Ctrl + ,**：把光标所在行切回 Markdown 源码
- **F5**：整页刷新渲染
- **F8**：导出当前页面为 `.md`
- **Ctrl + \\**：实时模式开关

最舒服的是「单行源码切换」。渲染完发现某个地方写错了，不用整段删掉重写，`Ctrl + ,` 就能回到源码状态，改完再渲染。它像写代码一样精准。

而且这些快捷键**只侦听、不吞键**。就算插件出问题，你的原生输入也不会被打断。

## 渲染范围，比想象中全

- 标题、列表、引用、表格
- 围栏代码块，自动识别语言，字体配色跟主题联动，可选显示行号
- 行内公式和块级公式，直接渲染成页面上的内容
- Mermaid、Flowchart、Sequence 图表，渲染成图片
- 待办清单、链接、图片

## 主题：20+ 套 Typora 主题

这是我最花心思的部分。

默认、GitHub、Dracula、樱花、水墨、丹枫……保守算 20 套以上。你喜欢的 Typora 主题 CSS，拖进主题目录就能换肤。

对写作者来说，主题不是装饰。同样的内容，在不同的排版和配色下，阅读体验完全不一样。写周报用清爽的 GitHub 风格，写读书笔记用水墨风，心情都会不同。

## 数据不出本机

所有渲染都在本地完成，笔记内容不会上传到任何服务器。

对很多人来说这可能只是个免责声明，但对笔记这种"什么私密内容都往里写"的载体，本地渲染是底线。

## 双向迁移

- `.md` 文件一键导入并渲染
- OneNote 页面一键导出 Markdown，图片自动归档到同名文件夹

这意味着你的笔记不是被锁死在某一个工具里。想迁移，随时能走。
